# BrowserTabRecorder

BrowserTabRecorder - расширение Chrome (Manifest V3) для записи активной вкладки браузера в файл WebM.

## Что умеет

- Записывает видео и звук активной вкладки.
- Может добавлять микрофон в запись (если выдали доступ).
- Показывает таймер и размер записи в popup.
- Позволяет вручную ставить запись на паузу и возобновлять.
- Может автоматически остановить запись в заданное системное время или через выбранный интервал.
- Может блокировать интерактивность страницы (мышь/клавиатура/фокус) для "чистой" записи.
- Позволяет отключить локальное воспроизведение звука через `Speakers: Off`, не убирая аудио из итогового файла.
- Не даёт компьютеру заснуть, пока сессия записи активна.
- Сохраняет результат через системный диалог `Save As`.
- Позволяет отменить текущую запись без сохранения (`Cancel`).
- При достижении лимитов (5 часов или 10 ГБ) предлагает:
  - продолжить запись,
  - или остановить и сохранить.
- Если вкладка закрыта во время записи, предлагает сохранить частичный файл.

## Установка

### Требования

- Google Chrome 116+
- Node.js 16+ (только для генерации иконок, если нужно)

### Шаги

1. (Опционально) Сгенерируйте иконки:

```bash
node scripts/generate-icons.js
```

2. Откройте `chrome://extensions/`.
3. Включите `Developer mode`.
4. Нажмите `Load unpacked`.
5. Выберите папку проекта `BrowserTabRecorder`.

## Как работает

- `popup/` - интерфейс управления записью.
- `service-worker.js` - координирует состояние, маршрутизирует сообщения между компонентами.
- `offscreen/offscreen.js` - захват медиапотока, микширование аудио, запись через `MediaRecorder`.
- `content/content-script.js` - проверка разрешений микрофона.
- `lib/audio-mixer.js` - микширование аудио вкладки и микрофона.

Пайплайн сохранения:

1. Для обычной ручной остановки popup открывает `Save As` по нажатию `Stop & Save`.
2. Если включена автоостановка, popup заранее запрашивает путь сохранения на старте записи.
3. После остановки offscreen собирает итоговый `Blob`.
4. Если для автоостановки путь был выбран заранее, offscreen пытается сразу записать файл напрямую в этот путь.
5. Если прямой автосейв недоступен или не удался, `Blob` передается через IndexedDB (а не напрямую через IPC).
6. Popup читает `Blob` из IndexedDB и записывает в выбранный файл.
7. Заранее выбранный save handle для автоостановки сохраняется локально и может быть восстановлен после повторного открытия popup как fallback.
8. Если popup недоступен в момент сохранения, расширение может открыть отдельную recovery-страницу и попытаться аварийно сохранить запись через browser downloads fallback.

## Использование

1. Перейдите на вкладку, которую нужно записать, и сделайте ее активной.
2. Нажмите иконку расширения.
3. Нажмите `Start Recording`.
4. При необходимости включите `Auto-stop`:
   - `Stop at time` - остановка по системному времени,
   - `Stop after interval` - остановка через интервал; на паузе этот отсчёт замораживается.
5. Если включена автоостановка, сразу выберите путь сохранения - он понадобится для автоматического сохранения без дополнительного клика.
6. При необходимости подтвердите добавление микрофона.
7. При необходимости включите `Input Lock` для отключения реакции страницы на ввод.
8. При необходимости используйте `Pause` / `Resume`.
9. Если не нужно слышать вкладку в колонках, переключите `Speakers: Off` - аудио всё равно останется в видеофайле.
10. Для завершения нажмите `Stop & Save`.
11. Если передумали, используйте `Cancel` (запись будет отброшена без сохранения файла).

## Ограничения

- Записывается только активная вкладка.
- После старта запись продолжится, даже если popup закрыть; при автоостановке offscreen пытается сохранить файл напрямую, а повторное открытие popup остаётся fallback-сценарием.
- Для автоостановки путь сохранения нужно выбрать в момент запуска записи.
- Формат вывода: WebM.
